# Access to servers

The code and distributable package do not contain access data from real servers. In the first configuration, the user enters the link obtained from the competition website or configures the data to which they have access.

Importing a link does not authenticate the person in GTC, does not verify registrations and does not prove authorization. The application only stores the data locally and transmits the connection request to the local rFactor 2 service. It is up to the organization and the server to control who can enter. A shared password can be resent by anyone who knows it; hiding the link in a website's interface does not solve this limitation.

Do not include configurations, real entry links, passwords, personal history or game installation files in Git. The `dist` folder must be generated by the script, without copying the user data folder. `.gitignore` excludes known application files.

Accepted import links only point to `http://localhost:5397/rest/multiplayer/join` or the `127.0.0.1` variant; the application builds the local request from the parameters. It does not open the pasted address as a page or use that URL to communicate with external services.

If a real password has been published, it must be changed by the organization. Deleting the file or making it private after publication does not guarantee deletion of copies.
