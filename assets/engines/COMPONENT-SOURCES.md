# Included component sources

The TinyPedal executable is unmodified; its Python library includes a modified integration for applying settings live. The modified files and their bytecode are in `SOURCE.zip/assets/tinypedal-live/`, under GPL-3.0-only. `build.ps1` inserts the bytecode into the package; regenerate it with Python 3.8.10 and `py_compile` on the two `.py` files. The Crew Chief executable remains unmodified. Original notices remain in `components`. Shared libraries can be replaced with compatible modified versions.

- TinyPedal **2.52.0**, GPL-3.0-or-later: `TinyPedal-2.52.0-source.zip` in this directory. Includes the project and pyACC, pyLMU and pyRfactor2SharedMemory submodules at the revisions pinned by the project. Source: https://github.com/TinyPedal/TinyPedal/tree/v2.52.0 . Revision: `bf43bd5db0cd15f57672e5c75696ced0df020781`.
- Qt **5.15.2**, LGPLv3 with third-party notices preserved: full source code, including build system, at https://download.qt.io/archive/qt/5.15/5.15.2/single/qt-everywhere-src-5.15.2.tar.xz . DLLs are in `components/TinyPedal/lib/PySide2`.
- PySide2 / shiboken2 **5.15.2.1**, LGPLv3: https://download.qt.io/official_releases/QtForPython/pyside2/PySide2-5.15.2.1-src/pyside-setup-opensource-src-5.15.2.1.tar.gz . Build documentation is included in the archive. Notice at `components/TinyPedal/docs/licenses/LICENSE.PySide2.txt`.
- Python **3.8.10**, PSF: https://www.python.org/ftp/python/3.8.10/Python-3.8.10.tar.xz . Licence preserved in `LICENSE.Python3.txt` in the same notices directory.
- psutil **6.1.1**, BSD-3-Clause: https://github.com/giampaolo/psutil/tree/release-6.1.1 . Licence in `LICENSE.psutil.txt`.
- Crew Chief **4.19.5.8**, MIT code: https://gitlab.com/mr_belowski/CrewChiefV4 . The original licence and notice are in `CREWCHIEF-LICENSE.txt` and the engine directory. Voice packs are downloaded separately from the official service; the code licence grants no additional rights to those sounds.
- rF2SharedMemoryMapPlugin, GPLv3, distributed in the engines' plugin directories: https://github.com/TheIronWolfModding/rF2SharedMemoryMapPlugin . Source and published versions are in the original project; the licence is preserved at `components/TinyPedal/docs/licenses/LICENSE.rF2SharedMemoryMapPlugin.txt`. The Companion installer uses version 3.7.15.1 in `components/rF2SharedMemoryMap`, with README, licence and provenance. Corresponding sources, including build projects, are in `rF2SharedMemoryMap-3.7.15.1-source.zip` in this directory; revision `48aa12dbb68849923870acd8e68044c46c3d83eb`.

The original Companion code, editable schemas, assets and build scripts are in `SOURCE.zip` (GPL-3.0-only). `prepare-components.ps1` pins versions and verifies SHA256 hashes of official archives before preparing the engines. External URLs give access to the original library sources at no additional charge; the remaining locally referenced source files accompany this package.
